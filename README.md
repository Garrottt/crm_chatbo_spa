## Descripción

Panel administrativo para gestionar el sistema de chatbot de spa. Permite visualizar conversaciones en tiempo real, gestionar reservas, clientes, campañas de marketing y especialistas.

## Stack

- Laravel + Blade
- Vue.js 3 + Tailwind CSS
- Axios (integración con API REST del ChatBot)
- Docker

## Módulos principales

- 📊 Dashboard con métricas de reservas y clientes
- 💬 Gestión de conversaciones con take-over manual del bot
- 📅 Agenda de citas con calendario
- 👥 Gestión de clientes y especialistas
- 📣 Campañas de marketing con seguimiento
- 🔐 Autenticación y portal de especialistas
